Rush Hour Garage
================

RushHourGarage.exe をダブルクリックして起動します。
exeだけを別のフォルダーへコピーしても遊べます。
Windows 10/11 x64向け。.NETランタイムは同梱しています。
Microsoft Edge WebView2 Runtimeが必要です（この開発環境では導入済み）。

赤い車を右の出口から出せばクリア。
車は向いている方向にだけ動きます。マウスでつかんでドラッグしてください。
2×2のショベルカーも、車体の矢印の方向へ動きます。

設定：6×6～12×12、難易度4段階。
設定を変更したら「新しいパズル」で反映します。
シードを空欄にすると毎回ランダム。同じサイズ・難易度・整数シードなら再現できます。
盤面の最短手数は、最後に出口へ出る1手も含みます。

「一手戻す」「やり直す」「ヒント」が使えます。
車をクリックまたはTabで選択し、矢印キーでも動かせます。
Shift＋矢印キー：移動できる端へ。
Esc：ドラッグの取り消し／遊び方を閉じる。

初回起動は内蔵ランタイムの展開に数秒かかる場合があります。
ゲームの保存機能はありません。後で同じ問題を遊ぶ場合は画面のコードを控えてください。
