## 実装したファイル

**`src/RushHour.Desktop/wwwroot/index.html`**
`lang="ja"` / UTF-8 / viewport / `base href="/"` / `app.css` / `#app`（走る赤い車の CSS アニメ付き起動プレースホルダ）/ `#blazor-error-ui`（既定非表示・再読み込みリンク・閉じる）/ `blazor.webview.js`（`autostart="false"`）→ `drag.js` の順。

**`src/RushHour.Desktop/Components/Game.razor`**
- ヘッダー（ブランド＋`OFFLINE`/`DESKTOP` バッジ＋遊び方）／左カラム／盤面／フッターの 3 段グリッド。
- 左カラム：スコアボード（手数・時間・最短）→ ステータス帯 → 4 ボタン（`新しいパズル` は主役のオレンジ、`一手戻す`/`やり直す` は 2 列、`ヒント` は琥珀色）→ ヒント／エラー通知 → 設定（サイズ 6〜12・難易度 4 段・シード）→ メタ情報（難易度・盤面・コード）。disabled 条件は手数 0・盤面なし・生成中・クリア済みで個別に判定。
- 盤面：`#game-board` は `style="--size:…; --exit:…"`、padding/border なし・`aspect-ratio:1`・`position:relative`。枠（コンクリート縁石）は外側の `.board-shell` 側に持たせたので測定矩形は汚していません。グリッド線と路面のざらつきは背景グラデーションのみ（DOM を増やしていません）。
- 車両は `@key` 付き `<button class="vehicle">`、`data-id/x/y/w/h/axis/target` はすべて整数・`left/top/width/height` は `Css()` で invariant 出力、移動系のイベントハンドラは一切付けていません（JS 専任）。
- 出口：出口行を暖色に染めたレーン＋破線ガイド＋路面の `EXIT` 文字、盤面外に脈動するシェブロンと「出口」タグ。赤い車が右へ 1 マスはみ出せるよう `overflow: visible`、`.stage` に右余白を確保。
- 生成中オーバーレイ、クリアオーバーレイ（CLEAR スタンプ・手数/タイム/最短・最短達成判定・次のパズル/同じ盤面・シード固定時の注意）、遊び方モーダル（目的・操作・キーボード・難易度の手数レンジ・「最短」の意味・シード・ヒント）。

**`src/RushHour.Desktop/Components/VehicleArt.razor`**
- 常に「進行方向 = X 軸、右が前」で描き、縦向きは SVG 内の `rotate(90) translate(0 -H)` だけで見た目を回転。盤面も DOM も軸平行のままです（CSS transform は車両ルートに一切かけていません）。
- 1 マス = 100 ユニット、座標はすべて整数なのでカルチャ非依存。`Generator.Expand` の分類（Car=2×1 / Truck=3×1 / Trailer=L×1 / Excavator=両辺 2 以上）に合わせ、トレーラーは長さ可変（リブをループ生成）、ショベルカーは 2×2・3×2・2×3 など縦横比が変わっても破綻しない比率計算にしています。
- 赤いターゲットは専用の造形（テーパーした低い車体・キャノピー・レーシングストライプ・リアウイング・テールバー）で他と一目で区別。ほかは乗用車（ルーフ＋前後ガラス）、トラック（白い箱＋カラーキャブ）、トレーラー（連結部つき長尺荷台）、ショベルカー（左右クローラー＋旋回体＋ブーム＋歯付きバケット）。
- 方向矢印は全車両のボディ中央に「暗い縁取り＋白」の二重ストロークのシェブロンで、どの車体色でも読めます。ターゲットだけ右向き二連、正方形のショベルカーは 1.35 倍に拡大。
- **グラデーション ID の重複を避けるため**、色依存の陰影は `color-mix(in srgb, var(--c), …)` の CSS クラスで解決し、共有グラデーション（`#va-shade` 立体感／`#va-glass` ガラス）は無彩色で `Game.razor` に 1 回だけ定義して全車両で参照しています。

**`src/RushHour.Desktop/wwwroot/app.css`**
暖かいオフホワイト＋濃いアスファルト＋オレンジのトークン設計、Windows 同梱フォントのみ（本文 Yu Gothic UI 系／数字 Bahnschrift）。押し込み感のあるボタン、`.hint` の脈動グロー、`.dragging` の浮き上がり、`:focus-visible` の破線アウトライン（レイアウトに影響しない `outline` を使用）。盤面は `.stage` のコンテナクエリで `min(100cqw,100cqh)` の正方形にし、1180×820 では約 700px、850×620 でも約 500px を確保して 2 カラムが崩れません。`prefers-reduced-motion` にも対応。

## 申し送り 2 点
- ブリーフの「`.vehicle-art` を 5% inset」は、辺の長さが違う車両だと縦横で余白がズレるため、**余白を SVG の座標側（マス比で均一）に持たせて `.vehicle-art` は `inset: 0`** にしました。見た目の隙間はマス比で一定です。
- `Won` 時は Core 側が赤い車を動かさず勝利フラグのみ立てる仕様なので、脱出の最終位置は描画されません。クリアオーバーレイで覆う構成にしてあります。
